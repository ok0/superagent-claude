# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background or identity. We act and communicate in ways that are welcoming, respectful and constructive.

## Scope

This code applies to project spaces: issues, pull requests and discussions in this repository.

## Reporting

Report unacceptable behavior to the maintainer (GitHub user ok0) through GitHub. For a sensitive report, open an issue that only asks for a private contact channel, with no details in it. Reports are handled confidentially.

## Enforcement

The maintainer follows the Contributor Covenant 2.1 enforcement guidelines when responding to a report.
